A program that writes an original two-sentence horror story to /output/entry.txt: an unnamed soldier appears in every one of a grandfather's war photographs, and now turns up in the narrator's son's birthday photo — the man who tucks him in.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
